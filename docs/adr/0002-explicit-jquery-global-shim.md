# Explicit jQuery global shim instead of relying on bundler auto-globals

`jquery-pjax` (a bare IIFE with no internal `require`/`import` of jQuery) and `events.js` (`export default globalThis.jQuery({})`, used as a pub-sub bus) both need `window.$`/`window.jQuery` set before their own module bodies run. The webpack build achieved this via `expose-loader`, which is necessary because jQuery's own UMD wrapper detects webpack's CommonJS-like module environment and deliberately suppresses its usual auto-global assignment. Vite/Rollup present the same class of module environment to that same UMD check, so `import 'jquery'` alone does not set the global there either. Rather than depend on bundler-internal UMD detection behavior (fragile across tool versions/config changes and not something we control), we added one explicit shim — a tiny module doing `import $ from 'jquery'; window.$ = window.jQuery = $;` — as the first import in `mandelbrot.js`, ahead of `jquery-pjax`. Every other component (`frame.js`, `navigation.js`, `tree.js`, `browser.js`, `preview.js`, `pen.js`, `search.js`) only references the global `$` inside function bodies that run later at runtime, so this single shim placed first covers the whole import graph without per-file changes.
