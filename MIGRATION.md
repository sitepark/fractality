# Migration guides

One guide per migration, because they are unrelated and a reader is almost never
doing both at once.

| Guide                                                                         | For you if…                                                                                 |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [`@frctl/fractal` → `@fractality/*`](docs/migration/fractal-to-fractality.md) | You are coming from the original Fractal and moving to this fork.                           |
| [`@fractality/web` 0.x → 1.0](docs/migration/web-0-to-1.md)                   | You already use Fractality and are upgrading to the release with the client-rendered Frame. |
